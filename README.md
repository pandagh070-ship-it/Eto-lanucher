# Eto Launcher

A Minecraft Java launcher for Android based on the open-source PojavLauncher project.

The goal is a landscape-first custom Eto interface while preserving the underlying launcher engine. Build output will be generated with GitHub Actions after the source integration is configured.

Upstream project: https://github.com/TeamPojavLauncher/PojavLauncher
